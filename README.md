# Roblox Delta Script for Murder Mystery 2 - Halloween Candy Collection

This Roblox script is designed for the Murder Mystery 2 game, specifically for the Halloween update. It allows players to collect candies by teleporting to them instead of flying through walls and floors. The script includes features to get unstuck if the player gets stuck in a wall or floor, highlight all candies in the game, and collect 50 candies before resetting the game. This script is perfect for enhancing the Halloween experience in Murder Mystery 2.

## Install

1. **Download the Script**: Download the `TeleportToCandies.server.lua` script from the GitHub repository.
2. **Place the Script**: Place the `TeleportToCandies.server.lua` script in the ServerScriptService of your Roblox game.

## Use

1. **Run the Game**: Start the game in Roblox Studio.
2. **Use the UI**: The UI will appear on the player's screen with buttons to teleport to the nearest candy, get unstuck, and highlight all candies.
3. **Collect Candies**: Click the "Teleport to Candy" button to teleport to the nearest candy. Collect 50 candies to reset the game.
